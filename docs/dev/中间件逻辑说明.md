# 中间件逻辑说明

> 请使用插件 Markdown Preview Mermaid Support 查看流程图

```mermaid
graph TB
    A([开始]):::startend --> B(error):::process
    B --> C{是否使用 HTTPS}:::decision
    C -->|是| D(SSL):::process
    D --> E(cert-file):::process
    E --> F(favicon):::process
    C -->|否| F
    F --> G(common):::process
    G --> H{是否启用 CORS}:::decision
    H -->|是| I(cors):::process
    H -->|否| J(cache):::process
    I --> J
    J --> K(404):::process
    K --> L(body-parser):::process
    L --> M(routes):::process
    M --> N{diy-middleware 是否存在}:::decision
    N -->|是| O(diy-middleware):::process
    N -->|否| P(mock):::process
    O --> P
    P --> Q([结束]):::startend
```
